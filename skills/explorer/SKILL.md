# Explorer（本地只读探查）

把「在不熟悉的本地仓库里找代码」这类多角度检索外包给原生子代理，让主 agent 不必自己铺开搜索。产出是消息文本，不是文件。

## 何时委派、何时主 agent 自己做

委派：仓库/模块结构陌生，需要一到多轮并行检索，需要跨层、跨目录找同一模式的实现，需要确认符号的真实定义与引用位置，或需要少量只读历史证据（哪次提交引入、某行归属）。

主 agent 直接做：调用方已给出确切文件、符号或路径，一次定向检索就能答完。**除非请求明确要求使用子代理**，否则不要为一个已知文件启动委派。

不属于本角色：外部文档、本地检出之外的 OSS 源码与供应商资料、版本与发布说明、网络研究——交给 `librarian`；也不用于实现、修复、重构或任何写操作。

## 子代理选择（本次调用临时生效）

1. 调用方显式指名的模型或子代理类型优先，只要运行时可用且已授权，不要静默替换；不可用时说明限制，不把下面的偏好当作替换授权。
2. 若运行时本次调用提供模型选择，先用其模型发现能力确认可用、已授权的候选与实际模型 ID。在满足只读本地检索、工具调用与任务所需上下文能力（不联网）的候选中，若有可核实的成本/速度分级，优先选已知既便宜又快的；否则优先 Flash／轻量档模型，例如 `deepseek-flash`。该名称只是偏好示例，不保证在当前运行时存在，不直接当作调用 ID；只有实际返回或经运行时确认可用、已授权的精确路由才可使用。价格/速度未知不妨碍按此偏好选择，但不能据此宣称更便宜或更快。
3. 没有选择器，或没有能力足够的可用模型候选时：改用文档化的、具备同样能力的原生轻量只读类型。偏好模型不可用时也按此规则回退，不自行拼接模型 ID，不为轻量偏好牺牲必需能力。
4. 披露条件式：运行时给出成本或延迟事实就照实引用，拿不到才说明「价格与速度未核实」，不要一律写成未知。任何时候都不自动宣称更便宜或更快，不把 Flash 名称、类型名或低 effort 当便宜证据。
5. 价格或速度未知本身不是退回更重运行时默认的理由：存在第 2 条符合偏好的可用模型，或第 3 条能力足够的文档化轻量类型时，优先使用。只有两者都没有时，才说明「无法确认是否轻量/快速」，并在请求允许时使用运行时默认，同时披露这一点。
6. 不写配置、agent 定义或全局设置，不自动升级、不重试加派；请求明确只接受已证实的低成本/快速子代理而缺少所需价格/延迟证据时（只有偏好模型或轻量类型也算）按阻塞报告，不改用主线程、CLI 或第二个进程顶替。
7. 不编造模型 ID，不强制绑定厂商或保证价格/速度；允许上述可选偏好示例，实际选择以本次运行时授权与能力为准。模型与价格相关的说明只写在主 agent 的调用说明里，不进 `<request>`／`<results>`。

## 委派方式

1. **完整读取** [角色正文](references/role.md)，包括末尾约束，不要只读开头。
2. 把该文件**完整正文逐字粘入**子代理提示词，不改写、不压缩、不用「按上面的角色说明执行」代替。
3. 正文之后只补本次最小上下文：`PROJECT_ROOT` 绝对路径；任务意图与范围边界（找什么、不找什么）；深度 `quick`、`medium`（默认）或 `very thorough`（这是检索深度：波次、范围宽窄与答案详细程度，不是模型或 effort 档位）；输出按角色正文规定的 `<request>`／`<results>`，路径一律绝对。
4. 能力映射、检索纪律、输出块格式、只读与范围约束全部以角色正文为准，此处不重复；子代理已在提示词里拿到完整角色，不要让它再加载本 skill 或其他参考文件，也不要让它再委派。

运行时完全没有子代理能力且请求明确要求委派时，同样是阻塞项：如实报告缺口，不静默改为主线程执行。

## 边界

- 只读：不编辑、创建、删除、移动文件，不写临时文件；不联网、不访问外部服务（外部研究走 `librarian`）。
- 不执行构建、测试、lint、格式化、安装；不写用户、项目或 agent 配置；不启动其他子代理。
- 范围限于 `PROJECT_ROOT` 与任务明确给出的路径；git 历史只读且仅在任务需要时使用。
