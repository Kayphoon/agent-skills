# Librarian（外部资料只读研究员）

完整行为、证据格式、失败恢复与只读约束都在 [`references/role.md`](references/role.md)，本文件只讲何时委派、怎么选子代理、怎么发起。本目录自包含：来源与修改说明见 [`NOTICE.md`](NOTICE.md)，许可见 [`LICENSE.txt`](LICENSE.txt)；不依赖仓库其他文件或已注册 agent。

## 何时用 / 何时不用

- 用：外部库 / OSS / 厂商 API 的官方文档、实现源码、版本差异、issue/PR、变更历史，且结论要能引用核验。
- 不用：调用方已给出单个 URL 的一次性抓取（主线程直接抓）；本地仓库/工作树调查（explorer 边界，本角色只返回边界）；无外部来源的纯概念问答。
- 调用方明确要求委派时走下面流程，不得静默改成主线程。

## 子代理选择（本次调用临时生效）

1. **调用方显式点名**的模型或子代理类型优先：运行时可用且已授权就用，不静默替换；不可用时说明限制，不把下面的偏好当作替换授权。
2. 若运行时本次调用提供模型选择，先用其模型发现能力确认可用、已授权的候选与实际模型 ID。在满足必需能力（只读、网页/远程源码读取、工具调用与任务所需上下文）的候选中，若有可核实的成本/速度分级，优先选**已知既便宜又快的**；否则优先 Flash／轻量档模型，例如 `deepseek-flash`。该名称只是偏好示例，不保证在当前运行时存在，不直接当作调用 ID；只有实际返回或经运行时确认可用、已授权的精确路由才可使用。网页与远程源码读取能力由实际工具及权限提供，不能仅凭模型名称假定具备，也不为轻量偏好牺牲必需能力。
3. 没有选择器，或没有能力足够的可用模型候选时：退到能力符合的文档化轻量只读类型。偏好模型不可用时也按此规则回退，不自行拼接模型 ID。存在第 2 条符合偏好的可用模型或本条轻量类型时，**价格/速度未知不妨碍按偏好选择**，也不是改用更重运行时默认的理由。有到手的事实就引用该事实，拿不到才说明「价格与速度未核实」；不把 Flash 名称、「轻量/快速」标签或低 effort 当便宜证据，不保证价格/速度。
4. 只有第 2 条没有能力足够的已知便宜+快候选或符合偏好的可用模型、且第 3 条也没有能力足够的文档化轻量类型时，才说明无法确认是否轻量/快速，请求允许才退到运行时默认并披露。请求只接受**已证实的**便宜+快时，无论有没有偏好模型或轻量类型，缺少所需价格/延迟证据就在派发前按阻塞报告，不改用外部 CLI 或常驻服务顶替。
5. 以上都只作用于本次调用——不写持久配置 / agent 定义 / 全局设置，不自动升级或加派重试。可选模型示例不构成厂商绑定；不编造模型 ID 或价格，实际选择以本次运行时授权与能力为准，模型与价格/速度说明留在父 agent 的调用说明里，不混入子代理的研究交付。

## 委派必做

1. **完整**读取 [`references/role.md`](references/role.md)：从标题到最后一行，含约束、通信与 Instance 小节。
2. 该文件全文**逐字粘入**所选原生子代理的提示词——选了便宜的也不改这一步。不改写、压缩或翻译，不写"按上面的角色说明执行"，也不让子代理自己读该文件、加载本 skill、依赖父对话或再 spawn。
3. 角色正文之后追加实例小节，字段在发起前全部换成具体值：

```text
# Instance
REQUEST: <调用方原话目标与关键约束，不要换成你自己的概括>
TARGET: <具体外部库/仓库或官方站点；调用方给了版本、tag 或 commit 就写死具体值，没给写 "unspecified — 由研究员确认当前稳定版本">
ALLOWED_SCRATCH: <本次允许 clone 的绝对 scratch 路径；默认 none——无明确授权就只能只读远程访问>
OUTPUT: <期望交付；默认按角色正文输出契约：一行类型判定 + 短小逐条 Claim/Evidence/Explanation + 结尾 Open questions>
```

- `TARGET` 点名的版本/commit 是研究目标，不静默替换成 latest；`ALLOWED_SCRATCH` 须为已解析绝对路径，`none` 只关文件系统 clone，不关只读远程源码访问（指定 commit 的文件、某 ref 的代码搜索、托管平台 API）。空占位或"那个库"之类指代算未构造完成。

## 运行时限制

- 无原生子代理：如实报告限制，不编造已委派。
- 未要求委派时主线程可按同一角色正文执行并保持同一输出契约，同时说明是主线程执行及原因（用户默认路径不算静默降级）；明确要求委派则不静默降级、不换外部 CLI 或常驻进程。

## 子代理边界

只读：不写文件、不改配置 / agent 定义 / 模型设置 / 环境变量、不装工具、不用未获提供的凭据；调查仅限外部来源，唯一落盘是授权绝对路径的 scratch clone；不嵌套 spawn，结果交回主 agent。
